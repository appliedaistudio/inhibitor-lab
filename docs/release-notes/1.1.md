# Inhibitor Service 1.1 Release Notes

## Overview

Version 1.1 sharpens how AI technologists discover, evaluate, and observe the Inhibitor in action. The release spotlights real-time guardrails through the live demo, connects conceptual guides to the new “Inside the Inhibitor” narrative, and refines onboarding flows so teams can ship oversight-ready agents faster.

## Highlights

- Linked the hero banner directly to the Inhibitor Application Sprint and rewrote the introduction for AI technologists who need defensible, real-time guardrails.
- Streamlined the README into focused sections for core capabilities, compliance coverage, repository resources, and quickstart steps so new teams can navigate faster.
- Added [docs/inhibitor-inside.md](./inhibitor-inside.md) to narrate how the Inhibitor runs parallel rules and inference layers and emits structured outputs.
- Cross-referenced the sprint overview to the internal flow guide so readers can trace deeper reasoning during onboarding.
- Connected core capabilities, conceptual guides, and API references to the [Inhibitor Demo](https://iaas-demo.replit.app/) so stakeholders can watch live interventions alongside the theory and REST workflows.

## Adoption Guidance

- Start with the refreshed README to pick the capability you need, then jump into the Inhibitor Demo to see real-time guardrails before integrating.
- Walk through [Inhibitor Application Sprint](./inhibitor-application-sprint.md) with the new hero link to sequence discovery, testing, and rollout; keep the demo open in a split-screen to observe interventions as you go.
- Use [Inside the Inhibitor](./inhibitor-inside.md) to understand the decision layers powering the demo and align your prompts and policies with the structured outputs you expect.

## Looking Ahead

- Expand demo scenarios to cover additional compliance domains and recovery paths.
- Add more pre-wired quickstart recipes so teams can pair the decision flow with their agent frameworks in minutes.
- Deepen observability around live interventions to pair demo visuals with telemetry teams can ship to their monitoring stacks.
