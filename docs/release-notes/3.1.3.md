# Inhibitor Service 3.1.3 Release Notes

## Overview

This `inhibitor-lab` release aligns the repository with Inhibitor Service 3.1.3. It updates
the real-time application guide with simpler language and clearer limits for live rule
sets.

## Documentation changes

- Explain that executing a large rule set can raise cost and make response time harder to
  predict.
- Recommend small, focused policy documents that generate a small rule set for each
  deployment and purpose.
- Add generated rule count and runtime cost to testing and launch checks.
- Rewrite the full real-time guide in concise, everyday language while keeping its main
  structure and safety advice.

## Upgrade note

Review each live policy before deployment. Split broad policies by boundary, tool, or
risk, and load only the rules needed for that check. Measure rule count, cost, and delay
again after each policy change.
