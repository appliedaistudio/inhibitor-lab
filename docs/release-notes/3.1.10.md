## Agent intent and reasoning guidance

- Recommend that every agent proposal sent to Inhibitor include a concise summary of its
  intent, decision-relevant reasoning, and expected outcome.
- Clarify that this summary should be purpose-built context rather than private
  chain-of-thought, hidden model reasoning, or a full transcript.
- Align the API integration guide, ROA pattern, and real-time application guidance around
  this recommendation.
