# Supported benchmarks

This directory contains maintained, reproducible benchmark workflows. A supported package owns its version-controlled scenarios, executable source, tests, reporting code, canonical evidence, derived reports, and explicit interpretation boundaries.

## Packages

- [`runtime_trajectories/`](runtime_trajectories/) — the maintained runtime trajectory safety benchmark, combining live Inhibitor signal evidence with deterministic compatibility mapping and controlled, no-side-effect controller/tool-boundary evaluation.

Historical and provenance-only material belongs in [`../legacy/`](../legacy/); diagnostics are not supported benchmark evidence.
