# Support Level Matrix

| Benchmark area | Category | Status | Support level | What it evaluates | What it does not evaluate | Acceptable public claim |
| --- | --- | --- | --- | --- | --- | --- |
| `legacy_ieb` | legacy | historical | historical | Archived IEB artifacts and prior benchmark evidence retained for traceability. | Current benchmark-suite execution or current Inhibitor behavior unless rerun under the current protocol. | Historical benchmark artifacts are preserved for traceability and comparison with prior work. |
| `capability_validation` | core | implemented | native | Current Inhibitor API compatibility and response shape through exposed `/check`, `/catalog`, schemas, observations, predictions, rules output, and supported modes where applicable. | Full safety efficacy, runtime enforcement, or production unsafe-action-prevention and safe-task-completion rates. | Native-support API contract and response-shape validation passed for the reported run. |
| `observation_normalization` | core | implemented | native | Native observation-normalization-compatible outputs exposed by current Inhibitor behavior. | Native runtime decisions, runtime enforcement, or end-to-end safety efficacy. | Native-support observation-normalization validation passed for fixture-defined cases in the reported run. |
| `decision_compatibility` | core | implemented | compatibility_mapped | Deterministic mapping from current Inhibitor outputs into the runtime-decision vocabulary. | Native runtime-decision enforcement or production enforcement behavior. | Compatibility-mapped decisions matched fixture expectations for the reported run. |
| `runtime_trajectories` | core | implemented | simulated | Deterministic benchmark-controller or harness proxy outcomes around current Inhibitor outputs. | Native runtime enforcement, production unsafe-response prevention, or production safe completion. | Simulated trajectory proxy outcomes matched fixture expectations for the reported run. |
| `operational_stress` | diagnostic | retained diagnostic | diagnostic | Load, latency, throughput, errors, timeouts, and degradation behavior when diagnostic execution is available. | Direct safety efficacy or native runtime enforcement. | Operational stress diagnostics provide run-specific operational maturity evidence when executed. |
| `semantic_context_robustness` | diagnostic | retained diagnostic | diagnostic | Long-context robustness and semantically rich embedded-instruction diagnostics, including risky, indirect, or hidden instructions embedded inside larger contextual inputs. | Direct production safety efficacy, native runtime enforcement, or replacement for core suite claims. | Semantic-context diagnostics provide conservative robustness evidence only, not direct safety-efficacy proof. |

Diagnostic rows describe reporting interpretation for retained diagnostic materials and planned diagnostic suite areas. The executable-suite manifest remains the source of truth for current runner implementation status.
