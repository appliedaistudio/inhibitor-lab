# Archived semantic-context robustness diagnostics

This historical category evaluated semantically rich, long-context prompts with embedded unsafe instructions. It contains the archived [`inhibitor_large_context_stress_test.ipynb`](inhibitor_large_context_stress_test.ipynb), its [`comprehensive_cybersecurity_article.txt`](comprehensive_cybersecurity_article.txt) fixture, and versioned [`semantic_context_results/`](semantic_context_results/).
