# Legacy diagnostics

This directory archives historical diagnostic result artifacts that predate the current benchmark-suite structure.

These archived outputs are retained for traceability and retrospective analysis only. They are not current benchmark-suite execution outputs, they do not belong under `benchmarks/results/`, and they should not be reported as current production safety-efficacy evidence.

Current retained diagnostic notebooks and reusable fixtures live under [`../../diagnostics/`](../../diagnostics/). Future live diagnostic execution remains a separate controlled task with reviewed methodology and fresh result publication.
