# Legacy benchmarks

This directory contains historical benchmark implementations and result artifacts preserved for provenance, reproducibility, publication history, and historical comparison. Legacy material may remain valuable for research, comparison, and retrospective analysis; **legacy does not mean useless or invalid**.

These assets are not the authoritative execution path for new runs. Archived notebooks may depend on older APIs, schemas, assumptions, fixtures, or methodologies. Use [`../supported/`](../supported/) for maintained benchmark execution, and do not represent historical results as current supported evidence.

## Collections

- [`diagnostics/`](diagnostics/) — historical operational-stress, semantic-context robustness, and drift-audit implementations and outputs.
- [`ieb/`](ieb/) — historical IEB benchmark versions and publication artifacts.
