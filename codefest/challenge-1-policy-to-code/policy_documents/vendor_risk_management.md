# Vendor Risk Management (VRM) – Requirements (v1.8)

- Vendors must provide a current SOC 2 Type II report or ISO 27001 certification.
- If a critical vendor's SOC 2 report is older than 15 months, flag for audit and restrict new data sharing.
- DPIAs must be performed for vendors processing EU resident data.
- If vendor fails annual security questionnaire, escalate to Security and restrict integrations until remediation.
