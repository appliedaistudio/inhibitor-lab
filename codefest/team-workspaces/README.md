# Team Workspaces

Use this directory as the shared area for team code submissions during Codefest.

## What to create for each team

Create one folder per team using a stable name (for example, `team-alpha`, `team-03`, or `team-ml-guardians`).

Example structure:

- `team-workspaces/team-alpha/`
- `team-workspaces/team-bravo/`
- `team-workspaces/team-charlie/`

A starter file is available at `team-workspaces/team-template/README.md`.

Team projects are expected to include AI agents where relevant to the challenge. Teams may use provided starter agents or any agent framework they prefer.

If a team folder does not already contain a `README.md`, create one with:

- Team name and members
- Which challenge(s) are implemented
- Run/test instructions
- Any assumptions and known limitations
- License and copyright attribution details

## Required licensing and attribution for team submissions

All contributed code should be compatible with this repository's MIT license.

Add the following notice in each team folder `README.md` (or in a `NOTICE` file):

```text
Copyright (c) 2025 <Team Name / Author Names>

This team's submission is provided under the MIT License.

SPDX-License-Identifier: MIT
```

When third-party assets or libraries are included, teams should also document:

- Source URL/repository
- Upstream license
- Any modifications made by the team

## Staff note

During team onboarding, staff should create the team folder immediately so teams have a known place to stage and submit their work. If needed, staff can provide teams with an OpenAI API key for agent development workflows.
