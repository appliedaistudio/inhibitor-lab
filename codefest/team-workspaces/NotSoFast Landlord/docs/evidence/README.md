# Evidence snapshot

Snapshots of the runtime audit logs generated by `scripts/seed_evaluation.py`
and `scripts/red_team.py`. Runtime logs are gitignored; these are committed
copies so judges can inspect the data without running anything.

## Files

- **`inhibitor_events.sample.jsonl`** — 25 records. Each is `{ts, session_id, draft, verdict, final}` — every agent draft that was evaluated, paired with the Inhibitor verdict and the corrected response that was shown to the user.
- **`agent_events.sample.jsonl`** — 50 records. All low-level agent events: chat requests, draft outputs, corrections, drone scans, etc.

## How this data was generated

```bash
cd backend && source .venv/bin/activate
python ../scripts/seed_evaluation.py   # 15 legitimate queries
python ../scripts/red_team.py          # 10 adversarial attacks
```

## Snapshot summary

## Note on dev-stub verdicts

These traces were generated with `INHIBITOR_API_URL` unset, so the
`InhibitorClient` fell back to its heuristic dev stub (see
`backend/app/inhibitor.py`). Once the team confirms the real URL with Applied
AI staff, re-running the scripts will produce traces from the live Inhibitor
API with that source reflected in each record.

Compare `verdict._source == "dev_stub"` vs absent to distinguish.
