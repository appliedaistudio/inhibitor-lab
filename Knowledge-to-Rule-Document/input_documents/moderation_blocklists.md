# URL & Term Blocklists (v2025-01)

- Block any URL that matches the internal blocklist domain patterns.
- Block any message containing any of the listed restricted terms.
- If both allowlist and blocklist trigger, allowlist wins and log the conflict with rule IDs.
- Update cadence: at least once per week; do not apply an unverified list.

*Note: The actual list of domains/terms is loaded separately; this doc defines behaviors not the list content.*
